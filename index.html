Features

Built for Serious Learners

Every feature is designed around evidence-based language acquisition principles.

Oxford-Quality Definitions

Every card uses learner dictionary definitions with register labels and usage notes — not machine-generated paraphrases or raw translations.

Smart Synonym Networks

Related words are highlighted in cyan, building associative word networks that mirror how the brain naturally organizes vocabulary.

FSRS-Optimized Scheduling

Cards are structured for Anki's Free Spaced Repetition Scheduler. Retention targets backed by real learning data, not arbitrary intervals.

Multi-Sense Cards

Words with multiple meanings get numbered definitions, each with its own example sentence and synonym set — up to 3 senses per card.

Native Language Cues

Minimal L1 hints trigger recall without creating translation dependency. Just enough to anchor the meaning, never enough to become a crutch.

Morphemic Root Links

Latin and Greek root connections accelerate recognition of unfamiliar words. See how 'bene-' connects 'benevolent', 'benefit', and 'benediction'.

Integration

Seamless Anki Workflow

DeckForge outputs standard TSV files that import directly into Anki — no plugins required. Your scheduling data, review history, and FSRS parameters stay untouched. Cards update by matching the first field, so you never lose progress.

  • TSV import preserves existing scheduling data
  • Compatible with FSRS and legacy SM-2 scheduler
  • Syncs across desktop, iOS, and Android
  • Cards update without resetting review history
